Low-Fidelity Wireframes:

Before any colours or fonts were chosen, each page (Home, Services, Contact) was blocked out using plain grey boxes. The goal at this stage was to agree on the section order and layout before any visual design work started.

High-Fidelity Wireframes:

The High-Fidelity wireframes apply the final colour system to that same layout, with dark sections alternating with warm cream sections and gold accents. They also show the typography, navigation, spacing and interactive styling defined in style.css. The design is consistent across the 3 pages. The Home, Services and Contact pages are shown using screenshots of the actual built website.

Responsive Design:

Responsive design was implemented using CSS media queries so that the website can adapt to different screen sizes. CSS Grid arranges feature and service cards into columns on larger screens, while layouts are reduced at 900px and displayed in single columns at 600px or less.
The navigation is also adjusted for smaller screens, and spacing and font sizes are reduced to make the content easier to view on mobile devices.

My Contribution:

My main contribution to the project was the design and front-end styling of the XYZ Master website. I created the low-fidelity and high-fidelity wireframes to plan the structure and visual appearance of the website. I also developed the main CSS stylesheet used to control the layout, colours, typography, spacing, buttons, cards, hover effects and responsive behaviour.
