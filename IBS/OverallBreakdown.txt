1. Assignment Overview

The assignment is based on the MyLib Public Library Information System case study.

MyLib serves two main types of visitors:

Members using walk-in library services
Members using pre-booked study room reservations

The assignment requires the group to analyse the existing library processes and model them using ARIS. The case study specifically asks for:

A Collaboration Diagram
A Process Diagram for Walk-in Member Services
A Process Diagram for Pre-Booked Study Room Reservations
Three weaknesses in the current processes and corresponding improvements

All diagrams must be created using ARIS.
